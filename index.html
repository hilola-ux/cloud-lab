PaaS Deploy, IAM va Kod Xavfsizligi

GitHub Pages platformasi orqali server boshqaruvisiz veb-saytni ishga tushirish, kirish huquqlari (RBAC) va Branch Protection qoidalarini sozlash laboratoriyasi

☁️ Model: PaaS ⏱️ Ajratilgan vaqt: 45 daqiqa 🛠️ Asbob: Faqat brauzer

🎯 1. Nazariy Tushuncha va Maqsad

PaaS (Platform as a Service) — dasturchi yoki muhandisga operatsion tizim, veb-server (Nginx/Apache), tarmoq xavfsizligi kabi murakkab infratuzilma bilan bosh qotirmasdan, faqat o'z kodi va ma'lumotlariga e'tibor qaratish imkonini beradi.

Laboratoriya vazifasi: Mahalliy kompyuterda oddiy veb-sahifa tayyorlash, uni GitHub platformasiga joylash, GitHub Pages orqali bir necha soniyada jonli efirga chiqarish hamda loyihaga jamoaviy rollar (RBAC) va himoya siyosatini (Branch Protection) joriy etish.

🚀 2. Amaliy Bosqichlar

1-QADAM Mahalliy index.html faylini yaratish

Ish stolida yangi matn hujjati yarating, uning nomini va formatini index.html ga o'zgartiring hamda quyidagi kodni Bloknot (Notepad) orqali kiritib saqlang:

2-QADAM GitHub-da Repozitoriy Ochish va Faylni Yuklash

  1. Brauzerda github.com saytiga kiring va profilingizdan «New repository» tugmasini bosing.
  2. Repozitoriy nomiga cloud-lab deb yozing va kirish huquqini Public holatida qoldiring.
  3. «Create repository» tugmasini bosing.
  4. Keyingi oynada «uploading an existing file» havolasini bosing va tayyorlagan index.html faylingizni yuklab, «Commit changes» tugmasini bosing.

3-QADAM GitHub Pages orqali Deploy qilish (PaaS Amaliyoti)

  1. Repozitoriyning yuqori menyusidagi «Settings» bo'limiga o'ting.
  2. Chap ustundagi ro'yxatdan «Pages» bandini tanlang.
  3. Branch qismida `None` o'rniga `main` ni tanlab, «Save» tugmasini bosing.
  4. 30–60 soniya kutib, sahifani yangilang (F5). Sizga jonli internet manzili taqdim etiladi:
    https://[profil-nomi].github.io/cloud-lab/

4-QADAM Kirish Nazorati (IAM / RBAC) va Rollar Taqsimoti

Loyiha sozlamalaridan «Collaborators» menyusiga kiring va «Add people» orqali guruhdoshingizga taklifnoma yuboring.

PaaS va korporativ muhitdagi asosiy rollar mohiyati:

Rol (Role) Huquq darajasi Xavfsizlik maqsadi
Read Faqat ko'rish va klonlash Audit o'tkazuvchilar va kuzatuvchilar uchun
Write Kod yuklash va tahrirlash Jamoa dasturchilari uchun
Admin To'liq boshqaruv (o'chirish, ruxsat berish) Faqat loyiha egasi va yetakchi mutaxassis uchun

5-QADAM Kod Himoyasi Siyosati (Branch Protection)

Asosiy kodni (main) ruxsatsiz o'zgartirish yoki tasodifan o'chirib yuborishdan himoyalash:

  1. Settings -> Branches bo'limiga o'ting.
  2. «Add branch ruleset» (yoki Add rule) tugmasini bosing.
  3. Target branch: `main` deb belgilang.
  4. «Restrict deletions» va «Require a pull request before merging» bandlarini faollashtirib, saqlang.
